# 塔罗学习 App —— 部署说明（零基础，全程网页点击）

这是一个**纯前端**小应用（没有后端、没有数据库），所有数据都存在打开者自己手机/电脑的浏览器里。
因此部署方式非常简单：只要把这几个文件放到一个能公开访问的网址上就行，推荐用 **GitHub Pages**（免费、永久在线、微信能直接打开）。

## 部署步骤（约5分钟）

1. **注册/登录 GitHub**：打开 https://github.com ，没有账号就免费注册一个。
2. **新建仓库**：右上角 `+` → `New repository`。
   - Repository name 填一个名字，比如 `tarot-learning`
   - 选择 `Public`（公开，这样才能被别人访问）
   - 其他保持默认，点击 `Create repository`
3. **上传文件**：进入刚创建的仓库页面 → 点击 `Add file` → `Upload files`。
   - **把本文件夹（webapp）里的内容**——`index.html`、`css` 文件夹、`js` 文件夹——**直接拖进浏览器上传区域**（不要连着 `webapp` 这个外层文件夹一起拖，要拖里面的东西，让 `index.html` 最终在仓库的最外层）
   - 拖入后往下滚动，点击绿色的 `Commit changes` 按钮
4. **开启 Pages 服务**：仓库页面顶部点 `Settings` → 左侧菜单点 `Pages`。
   - `Source` 选择 `Deploy from a branch`
   - Branch 选择 `main`，文件夹选择 `/ (root)`，点击 `Save`
5. **等待1-2分钟**，刷新这个 Pages 设置页面，会出现一行提示，给你一个网址，形如：
   `https://你的用户名.github.io/tarot-learning/`
6. 用手机（微信里直接打开这个链接，或先在浏览器打开再分享链接）测试一下，确认能正常使用。
7. **分享给朋友**：把这个网址发给任何人，对方点开就能用（每个人的学习记录只存在各自的手机/浏览器里，互不影响，也互不同步）。

## 以后要更新内容怎么办？

以后如果我帮你改了代码（比如换了图片、加了新功能），只需要把改动过的文件重新拖到仓库里覆盖上传一次，
Pages 会在1分钟内自动更新到线上，不需要重新走一遍上面的步骤。

## 数据备份提醒

因为数据只存在浏览器本地，换手机/清缓存前，记得在 App 里「设置」→「导出全部数据」，保存好那个 json 文件，
下次在新设备/新浏览器里通过「设置」→「导入数据」把它导回来即可。
